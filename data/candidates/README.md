# Candidates

Draft events that have **not** been verified to the project's standard. Files here are
never loaded by the site and never affect any counter — the data loader only reads
`data/events/*.json`. Use this folder as a staging area while researching.

Workflow: research a possible event → add a candidate file here → verify sources and
classification → promote it into `data/events/<year>.json` (for example with
`npm run add:event`) → delete the candidate.

See `TEMPLATE.json` for the event shape. A candidate is not required to be complete or valid.
